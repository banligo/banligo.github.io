# Logsite

Yingqiu 的个人静态网站，使用 Jekyll 构建。

## 内容结构

- `_diary/`：日记、学习记录和长文章
- `_pages/`：Diary、About、Archive 等固定页面
- `assets/images/`：网站图片
- `assets/documents/`：PDF 和其他文档
- `_layouts/`、`_includes/`、`_sass/`：页面模板和样式
- `_config.yml`：站点配置

`valentine/` 和旧的 `family-gallery/` 相册已移除。

## 本地预览

```sh
bundle install
bundle exec jekyll serve
```

然后打开 Jekyll 显示的本地地址。
