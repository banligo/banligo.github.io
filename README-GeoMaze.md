# GeoMaze

轻量级、无服务器的几何迷宫。沿用原有 `/seamshift/` 地址，避免旧链接失效。原生 ES modules + SVG，无运行时依赖。`npm run dev`、`npm test`、`npm run build`。

|关卡|核心机制|普通最短|三星最优 N3_opt|三星目标|
|---|---|---:|---:|---:|
|1 Broken Path|两种距离阈值、逐档连接范围、星片支路|8|10|12|
|2 Other Side|钥匙实体门、圆柱取钥匙、莫比乌斯折返、觉醒追击|7|9|11|
|3 Missing Piece|自由选槽、旋转、交换与跨区域复用碎片|10|12|14|
|4 Shadow Maze|拼图闭合屏障、对偶网络、边界绕行、守护星片|9|13|15|
|5 GeoMaze|两块自由碎片、三个槽位、围困影子取星、连接范围与两种折叠|18|29|32|

## 规则与数学

抵达终点且未死亡即获胜；不检查额外的尺度、拓扑或封印条件。钥匙通过真实门边控制通行。通关一星，达到步数目标或收集星片两星，两者兼备三星。普通最快成绩与最佳三星成绩分别保存；界面关卡选择列出理论最优、三星目标及个人三星成绩。

几何桥使用固定 seed 的微扰节点，刷新不会改变谜题；拥有实际绘制的节点坐标；距离为欧氏距离，只有 `distance <= radius` 才开放。节点各显示连接半径的一半，两个范围相遇恰好对应连边阈值。逐档调整范围，每档计一个回合；固定几何的连边随半径单调增加。虚线显示尚未开放的桥。

Cylinder 连接同一行，Möbius 反转行坐标；角点对偶对应 `height-y`。Shadow 只走角点网络；每条通道恰为交叉原始道路开闭的补集。紫色网络在有影子的关卡默认显示。旋转碎片和边界变化实时重建两类网络。守护星片初始显示淡轮廓；当影子到灯塔的路被阻断时点亮。

普通怪物在警戒范围内或取得钥匙时觉醒。觉醒状态持久保存，此后每个有效操作后按当前图的确定性 BFS 走一步。休眠显示 z，追击显示 !，没有路径显示“受阻”，虚线标记下一步。Shadow 向灯塔按关卡固定时钟移动。非法操作不计回合，碰撞优先于获胜。

## 验证与求解

`solver.js` 默认使用精确 A*，启发式仅使用放宽所有空间/拼图的联合图距离；含钥匙的当前关卡，钥匙都是抵达终点的实体必经门条件。启发式不计额外的旋转、放置、尺度和怪物成本，因此不会高估。最先弹出的获胜状态给出最少实际操作数。状态散列含觉醒、收集物、怪物、碎片、尺度、拓扑与行动时钟。只有提示 Worker 允许加权搜索，不用于最优成绩计算。

`tools/seamshift/solutions.json` 保存五关普通和三星完整操作序列。测试用真实 `transition` 逐步执行，检查有效操作、收集物、最终 `won`，并重新运行精确 A* 验证 N3_opt。第五关三星路线29步，不依赖静态可达性冒充可通关。

## 保存与重置

每回合安排合并保存，页面隐藏/关闭立即同步写入。`geomaze.adventure.v3` 保存当前完整状态、Undo 历史、成绩、解锁、发现与教学。新关卡采用版本3存档，旧版存档保留在原键中但不导入不兼容地图或成绩。

Restart Level 仅重置当前尝试。关卡菜单中的 Reset All Progress 先显示确认对话框；确认后删除 GeoMaze 及两代旧存档键，再立即初始化第一关。其他网站数据不受影响。

## 手机与部署

保留可见视口适配、安全区、44px控件、滑动、点击放置与拖拽。手机关闭持续动画、简化墙体、增量更新 SVG 层；保存不复制全部历史，输入 FIFO 与动画独立。范围提示和对偶线条使用静态 SVG，无额外引擎。

生产构建输出 `dist/seamshift/` 和相对路径资源；Jekyll/GitHub Pages 直接复制原目录。路径仍为 `/seamshift/`，显示名称统一为 GeoMaze。`tools/`、`dist/` 不进入 Jekyll 站点。
