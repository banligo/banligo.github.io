##### Main story

Critical-point statistics are useful because filament/wall counts can access smaller smoothing scales while still remaining perturbatively usable. This gives extra cosmological information beyond the conservative large-scale baseline.

The core result should be:

- `R = 40`: conservative / valid regime. Use this to establish the baseline.
- `R = 30, 20`: use filament/wall only. Peak/void theory may already be less stable, but filament/wall can still be useful.
- Quantify the gain with uncertainty ratios such as `sigma_R=30 / sigma_R=40`, `sigma_R=20 / sigma_R=40`, or with a FoM improvement.

So the main paper should be built around points 1 and 2. The beyond-standard-parameter part is interesting, but it should stay as an extension.

##### Suggested paper structure

###### 1. Standard-parameter inference at `R = 40`

This is the baseline analysis, and it is already mostly done.

Parameter set:

`theta = {Omega_m, Omega_b, h, n_s, sigma_8}`.

Show:

- all CPs combined;
- peak, void, filament, and wall separately;
- optionally, comparison with `P(k)`.

Main conclusion:

CP statistics have real constraining power already in the conservative `R = 40` regime.

###### 2. Smaller-scale gain from filament/wall

This should be the main new result of the paper.

Do the standard-parameter inference for:

- `R = 40`;
- `R = 30`;
- `R = 20`;

but using only filament/wall statistics.

The point is not to claim that all CP statistics are reliable at small `R`. The cleaner statement is:

> Filament/wall counts remain perturbatively useful down to smaller smoothing scales, so they extract additional information that is not available from peak/void counts in the conservative regime.

Include a table like:

| Statistic | sigma(Omega_m) | sigma(Omega_b) | sigma(h) | sigma(n_s) | sigma(sigma_8) | Improvement |
|---|---:|---:|---:|---:|---:|---:|
| filament/wall, `R = 40` |  |  |  |  |  | baseline |
| filament/wall, `R = 30` |  |  |  |  |  | `sigma_30 / sigma_40` |
| filament/wall, `R = 20` |  |  |  |  |  | `sigma_20 / sigma_40` |

If the covariance allows it, also report a FoM improvement.

###### 3. Beyond-standard parameters as an extension

This should not become the main paper. Avoid fitting the full large parameter set

`{w_0, sum m_nu, Omega_m, Omega_b, h, n_s, sigma_8}`

all at once, because it will make the story too broad.

A cleaner setup is to split it into two proof-of-concept extensions:

- neutrino mass: `{sum m_nu, Omega_m, sigma_8}`;
- dark energy: `{w_0, Omega_m, sigma_8}`.

For each case, compare:

- `ALL_CP, R = 40`;
- `filament/wall, R = 30`;
- `ALL_CP, R = 40` + `filament/wall, R = 30`.

The claim should be worded carefully:

> Adding a smaller-scale filament/wall statistic can improve sensitivity to neutrino mass or dark energy beyond the conservative `R = 40` analysis.

This is better framed as a proof-of-concept extension, not as a final survey forecast.

###### 4. Next-order appendix

Put the next-order calculation in the appendix. It supports the method, but it should not become the main storyline.

Possible wording in the main text:

> The leading-order prediction captures the dominant signal in the chosen regime. We also derive and test the next-order correction in Appendix X as a first step toward extending the validity of the model to smaller smoothing scales.

###### 5. Stability tests

Minimum checks to include:

- `N_sim` dependence;
- covariance stability;
- binning stability;
- smoothing-scale robustness.

The most important one is covariance stability. For example, compare posteriors with

`N_sim = 300, 500, 1000`

and check whether the constraints are stable.

##### Positioning

A compact way to position the paper:

> This work demonstrates that critical-point statistics provide competitive cosmological information, and that filament/wall counts can extend perturbative morphology-based inference to smaller smoothing scales, leading to improved constraints on both standard and beyond-standard cosmological parameters.

Priority:

- Main result: standard parameters at `R = 40` plus small-scale filament/wall improvement.
- Extension: neutrino mass and `w_0`.
- Appendix: next-order correction.
- Validation: stability tests.
