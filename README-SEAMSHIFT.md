# SEAMSHIFT · 缝隙之间

五关独立策略解谜。打开 `/seamshift/` 直接进入当前关卡；用尺度、环绕与扭转边界、真实道路拼图改变迷宫。首页“实习与项目经历”有游戏入口。

## 开发

Node.js 20+；原生 ES modules / SVG / CSS，无第三方运行依赖、CDN、后端或账号。

```sh
npm install
npm run dev
# http://127.0.0.1:5173/seamshift/
npm test
npm run build
```

生产构建检查 JS 语法和本地资源并生成 `dist/`。现有 Jekyll / GitHub Pages 直接复制 `seamshift/` 和 `assets/seamshift/`；资源均使用相对路径，可在子目录下部署。`dist/`、`tools/` 和 Node 开发文件已排除在 Jekyll 发布目录之外。

完整站点预览仍可使用 `bundle exec jekyll serve --host 127.0.0.1`。

## 游玩

- WASD / 方向键移动；手机可用方向盘或在地图上滑动。
- 1 / 2 / 3 切换尺度，T 循环切换平面、环绕（Cylinder）、扭转（Möbius）。
- 点碎片选择，再点同纹样空位放置；再次点击碎片旋转。支持拖放、旋转按钮与收回按钮。放置、旋转、收回均消耗一回合；选择与预览不消耗回合。
- Z 撤销，R 重开，Space 等待，H 查看渐进提示。前两次只提示观察与机制，第三次才搜索当前状态的一步建议。
- 眼睛按钮 / 地图聚焦时的 Tab 切换网络显示。操作帮助和发现手记可选打开。
- 1 星为通关；2 星为不超过推荐步数；3 星还需取得可选星片。1 星即可解锁下一关。
- 通关后星星依次点亮并自动进入下一关，轻触可跳过。第五关进入旅程完成界面。

localStorage 保存当前关卡、完整状态与撤销历史、解锁、最佳成绩、最高星级、已看提示与发现手记。刷新继续当前进度；通关动画中刷新会直接进入已解锁的下一关。旧版存档只迁移完成记录与解锁，不虚构三星。存储损坏、被禁用或配额不足时仍可游玩。

## 关卡与评分验证

求解器通过实际回合引擎搜索，包含两类怪物、拼图状态与行动周期；测试逐步重放每条解。推荐步数取自已验证的星片路线，不声称为最短路线。

| 关卡 | 主要发现 | 普通路线 | 星片路线 / Par |
| --- | --- | ---: | ---: |
| 1 · Broken Path | 移动与尺度 | 7 | 9 |
| 2 · Other Side | 环绕边界与缓慢小兽 | 4 | 8 |
| 3 · Missing Piece | 两块拼图与莫比乌斯 | 10 | 12 |
| 4 · Shadow Maze | 打开自己的路会阻断影子 | 8 | 12 |
| 5 · Seamshift | 三块拼图、三档尺度、两类怪物 | 20 | 28 |

第五关从几何上要求环绕取钥匙、扭转抵达终点、尺度 3 开启边缘地板和拼图接路。测试使用一个忽略门锁、接口与怪物的宽松超图，验证禁用这些机制后仍然不可达，从而排除普通路线绕过谜题的可能。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `levels.js` | 五关、`levelObjectives`、Par、教程与渐进提示 |
| `engine.js` | 纯回合转换、单一 `isLevelComplete`、评分、完整撤销 |
| `pieces.js` | 直路、弯路、T 形、十字接口与旋转规则 |
| `graphs.js` | 单调尺度过滤、边界识别、实际互补对偶图、确定性 BFS |
| `solver.js` | 完整状态哈希、周期、加权 A*，不保证最短解 |
| `hint-worker.js` | 后台搜索当前局面，不沿用失效答案 |
| `progress.js` | 存档校验、旧存档迁移、解锁、最高星级与最佳步数 |
| `input.js` | 有限 FIFO 操作队列、滑动识别、SVG 触摸坐标映射 |
| `board.js` / `icons.js` | 统一 SVG 美术、拼图、演员、怪物预测与边界端口 |
| `renderer.js` | 保留 SVG 与静态场景，只更新变化图层，避免每次移动重建全图 |
| `viewport.js` | 根据 visualViewport 与屏幕比例调整游戏高度，长屏控件自动上移 |
| `app.js` / `game.css` | 单关 UI、触控、自动推进、过渡、safe-area / 100dvh 响应式布局 |
| `tools/seamshift/game.test.mjs` | 规则、数学、五关路线、评分、存档与输入测试 |

## 数学规则

固定种子决定非关键绘制变化，关键通路手工设计保证解法稳定。道路具有出生阈值，在拼图布局与门锁状态固定时，随尺度满足边集单调包含。拼图节点只在放入碎片后出现，双方接口都开放才建立边。

原始节点是格子中心，对偶节点是角点。内部对偶边恰好穿过对应原始边，开闭互补；对偶图由实际原始图重建，拼图、门、尺度和拓扑全部参与计算。没有外部无限绕行区域。

圆柱格子中心边界映射保持行号；莫比乌斯格子映射 `H-1-y`，角点映射 `H-j`。上下边界封闭。切回平面时，识别缝上的影子确定性映射到最近内部角点 `x=1`，不会复制或丢失。

原推箱子、压力板、封印台系统已删除。所有必要目标由 `levelObjectives` 管理，同一回合结束后先判断碰撞与信标失败，再由 `isLevelComplete` 判断通关。星片只参与评分，不是通关条件。

所有操作可撤销，错误拼图可以旋转或收回；人物站在碎片上时禁止收回，但可旋转修复。提示搜索有深度与状态数上限，未找到路线会明确建议尝试收回或撤销。无实时计时压力；动画与逻辑分离，支持连续输入与 reduced-motion。

手机默认使用静态轻量场景，关闭持续动画和粒子。按钮与场景缓存复用；操作队列按屏幕帧执行。存档合并到短暂输入间隙写入，刷新或切到后台时立即保存，保留完整撤销记录。游戏按浏览器实际可见高度适配；长竖屏限制游戏区高度，使控件不落到屏幕最远端。
