# SEAMSHIFT — Labyrinth of Dual Worlds

五关回合制策略解谜。放大尺度接通道路，切换 Plane / Cylinder / Möbius 改变边界，用原始图的道路切断暗影的对偶网络。

游戏位于 `/seamshift/`；首页“实习与项目经历”第一项为入口。现有 Jekyll 会直接复制 HTML、CSS 和 ES modules，不需要额外前端构建，也不依赖 CDN、后端或账号。

## 开发与验证

Node.js 20+；没有第三方 npm 依赖。

```sh
npm install
npm run dev
# http://127.0.0.1:5173/seamshift/

npm test
npm run build
```

`npm run build` 检查 JS 语法和 HTML 本地资源，并生成独立静态文件至 `dist/`。`dist/` 已被 Git 与 Jekyll 排除；GitHub Pages 直接使用 `seamshift/` 与 `assets/seamshift/` 原文件。

完整个人网站的本地预览仍使用：

```sh
bundle exec jekyll serve --host 127.0.0.1
# http://127.0.0.1:4000/seamshift/
```

## 操作

| 操作 | 电脑 | 手机 / 点击 |
| --- | --- | --- |
| 移动、推箱子 | WASD / 方向键 | 方向盘 |
| 选择尺度 | 1 / 2 / 3 | 尺度按钮 |
| 切换拓扑 | T 循环 | 边界规则按钮 |
| 激活封印台 | F | 激活封印 |
| 等待 | Space | 等待一回合 |
| 原始 / 对偶 / 双层视图 | Tab（地图聚焦时） | 地图上方切换 |
| 撤销 / 重开 / 提示 | Z / R / H | 对应按钮 |
| 主菜单 / 操作说明 | Esc / ? | 左上角标识 / 操作说明 |

悬停或用键盘聚焦尺度、边界按钮可预览新旧道路、暗影路径和相邻猎手风险，不推进回合。手机直接选择并可撤销。每次合法行动完成后，怪物按各自周期移动，最后判定胜负；非法动作不推进时间。没有实时倒计时。

箱子只能推；只有箱子压住压力板才激活。钥匙触碰自动收集，所有锁门随之开启。站在 T 上满足条件后按 F，封印在本次关卡中持续保留。所有对象、时钟、钥匙、封印与胜负状态都可完整撤销。

## 结构与数学

- `assets/seamshift/levels.js`：五张规定地图、固定种子、阈值、敌人周期、教学和机关条件。
- `graphs.js`：单调几何过滤、拓扑邻接、原始图、实际互补对偶图、确定性 BFS 和种子随机数。
- `engine.js`：纯函数 `applyAction` / `transition`，机关、敌人、预览、会话撤销。
- `solver.js`：完整状态哈希与加权 A*；通过真实引擎搜索，包含怪物位置和回合模周期。
- `hint-worker.js`：Web Worker 搜索当前局面；偏离最初路线后重新求解。
- `board.js`：SVG 双层网络、出生阈值、边界端口、敌人路径和几何变化预览。
- `app.js` / `game.css`：响应式界面、操作、弹窗与 localStorage 最佳成绩。
- `tools/seamshift/game.test.mjs`：数学与状态测试、五关搜索及实际重放。

格子中心是原始节点；格子角点是对偶节点。内部原始边开放时，穿过它的对偶边关闭，反之开放。箱子只阻挡角色，不改变几何边。上下外侧没有对偶节点，暗影不能通过无限外部区域绕行。

Plane 只使用内部角点。Cylinder 把 `(W,j)` 识别到 `(0,j)`；Möbius 把 `(W,j)` 识别到 `(0,H-j)`，而玩家格子中心的行映射为 `H-1-y`。切回平面时，位于识别缝上的暗影确定性映射到最近内部角点 `x=1`，每个实体只映射一次。信标使用相同映射规则。

地图关键结构与解法固定；种子只扰动绘制坐标。尺度 1、2、3 满足边集单调包含。第五关平面 r=3 的屏障确实切断对偶路径；圆柱和莫比乌斯会允许绕行，结论来自图搜索。

## 五关验证

求解器从初始状态搜索，逐步通过真实引擎重放；所有解均少于 50 次有效操作。加权 A* 优先寻找可行解，不保证最短解。

| 关卡 | 核心机制 | 已验证路线 |
| --- | --- | --- |
| 1 · Broken Bridge | 桥梁阈值、缩回尺度 | 6 回合 |
| 2 · Around the World | 圆柱边界、猎手 | 9 回合 |
| 3 · Twisted Room | 莫比乌斯翻转、推箱子 | 9 回合 |
| 4 · Shadow Barrier | 钥匙、尺度、对偶屏障 | 10 回合 |
| 5 · Topological Paradox | 三种拓扑、三档尺度、封印、两类怪物 | 22 回合 |

提示搜索有状态数与深度上限，找不到解时会说明并建议撤销，不沿用失效路线。成绩仅保存在当前浏览器；存储不可用时仍可正常游戏。开发服务器只提供游戏；完整站点使用 Jekyll 预览。
