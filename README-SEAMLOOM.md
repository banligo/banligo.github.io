# SEAMLOOM — A World of Twisted Paths

轻量级、无服务器的回合迷宫。原生 ES modules + SVG，没有运行时依赖。原 `/seamshift/` 地址继续使用；个人主页“实习与项目经历”保留入口。

运行 `npm run dev`，测试 `npm test`，生产构建 `npm run build`。Jekyll/GitHub Pages 直接复制游戏目录和相对资源路径。游戏使用独立 SVG favicon；首页 favicon 不受影响。

## 观察世界

打开即进入，画面从暗色中渐显约0.8秒。首次显示三条基础规则，4秒后淡出；提示和过渡不拦截操作。Help 可再次查看。Wait 按钮显示“等待”，或按 Space：原地不动并推进一个有效回合。首次遇到怪物时有一次简短等待提示。

所有星片从开始即可观察；未激活的显示淡轮廓。第三关的星片由连接范围激活。任何有效操作后均重新检查拾取，因此站在星片上调整范围也能获得；旧存档重进时也会补查。第二关星片位于真实可达的 `(0,2)`，搜索路线与回归测试包含实际拾取。

## 数学与规则

几何桥使用固定 seed 的微扰节点，真实欧氏距离满足 `d <= r` 才连通。两端各显示 `r/2` 的范围，并实际绘出向中间伸展的木质桥臂；范围是桥臂可伸达的标尺。桥板未接上时，断口下方可见水沟；两侧桥板接上后，真实图才允许通行。扩大范围保持边的单调激活。碎片接口、放置和旋转真正改变图；碎片均可使用任意槽位，可交换和回收。

Plane 封闭，Cylinder 左右同向周期，Möbius 左右反向识别；Torus 左右、上下分别周期识别。对偶点是瓦片角点，每条对偶边跨越一条原始边，开闭严格互补。Torus 使用 `width × height` 个周期角点，包含上下及左右接缝的对偶边。测试验证了环面上非收缩的闭合原始道路不一定分割对偶图。

普通小兽按当前原始图 BFS 追击，醒来后每个有效操作移动一步。Shadow 沿当前真实对偶图，在两个固定几何锚点之间往返；断路时停留，抵达锚点后折返。锚点不是失败或封印条件。

Shadow 影响其角点相邻的四块有效地板。边界相邻格按照当前空间识别，因此规则在接缝处也一致。细裂痕为当前实际陷阱，仅以空心菱形预告下一回合新出现的陷阱；不再绘制大面积紫色斜纹或重复虚线框。第四关影子固定不动，星片移到安全支路，三岔碎片减少旋转负担。回合结束时站在危险格才失败。关闭或打开玩家道路会改变紫色路线、Shadow 的移动及实际危险；可以等待、绕行或重新拼路。前五关只需抵达安全终点。第六至八关把控制 Shadow 变成可见的机关目标：Shadow 能沿紫色裂隙吸走守护灯的能量，所以门保持关闭；修建道路形成屏障后，灯安全充能，金线亮起，终点门实际开放。灯一旦点亮会存储能量，可以继续调整空间。门的开闭真实影响玩家图和对偶图，未点灯时不能先走进出口。

这里的“对偶”不是另一个平行宇宙，而是同一张地图中格子角点之间的路线网。玩家道路连接格子中心，与对偶裂隙逐条交叉；二者开闭互补。地图上的“米色是道路 · 紫色是裂隙”按钮提供一幅可选对照图；不用阅读公式也能观察交叉通道如何熄灭。

第六关用一条跨越平面的道路挡住影子，第七关用实际图连通性验证环面上的同一屏障会被绕过，而一个可收缩的小围栏能隔开 Shadow 与灯。第八关允许先用平面屏障点灯，再折叠空间寻找星片。`lampLit` 被真实操作触发，存档、求解器和 Undo 都完整保留，未硬编码胜利。

## 求解、存档与扩展

`tools/seamshift/solutions.json` 包含八关普通及三星完整操作序列。真实引擎逐步重放验证 `status === 'won'`。精确 A* 计算最少操作数；启发式放宽几何与怪物约束，状态散列包括全部怪物、巡游方向、回合时钟、碎片、收集物、拓扑和尺度。提示 Worker 可以使用加权搜索，成绩验证始终使用精确搜索。

新存档键 `seamloom.adventure.v4` 自动迁移 GeoMaze v3 / SEAMSHIFT v2 的解锁、星级、成绩、发现与教学。未改动地图的当前尝试与 Undo 原样升级；重做地图中不兼容的尝试存入 `archivedAttempts`，从该关新布局开始。原存档键不删除，以保留完整旧数据；不会因改名把用户送回第一关。

Restart 仅重开本关，历史成绩保留。Reset All Progress 必须确认，然后删除当前及所有旧版游戏键，初始化第一关；不清除其他网站数据。每回合合并写入存档，页面隐藏或关闭时立即保存。

手机保留可见视口与安全区适配、44px按钮、方向盘、滑动、点击拼图和拖放。SVG 分层更新，地图和地形缓存，手机无持续动画。旧的五关全通用户会自动解锁第六关，所有历史成绩保留。新关卡通过配置扩展；关卡推进和进度处理使用配置长度。
