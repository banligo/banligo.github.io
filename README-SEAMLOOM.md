# 几何迷宫 · Geometry Maze

15 关轻量级回合迷宫。复用原有原生 ES modules + SVG 架构，无新增运行时依赖、后端或游戏框架。地址继续使用 `/seamshift/`。游戏独立发布。

运行 `npm run dev`；安装开发依赖 `npm install` 后运行 `npm test`；生产构建 `npm run build`。Jekyll / GitHub Pages 使用相对资源路径。

## 怪物：先警觉，再追击

每只小兽有独立的 Sleeping → Alert → Chasing 状态。Sleeping 闭眼、不动、不攻击；Alert 睁眼并显示 !，这一回合保持原位。下一有效回合才沿当前道路 BFS 追一步。直接走进小兽占据的格子被拒绝，不会以“睡着却咬人”的方式处理。守桥者可以在配置中初始已警觉，并在开局清楚显示。

警戒按真实道路距离计算，淡金虚线格展示真实范围，墙、端口和断桥都会影响范围。普通钥匙不触发全图警报。2、8、10 关有明确标注声波的带铃钥匙，听觉范围分别为 4、6、4 步道路，声音也是一次移动的一部分，不额外增加回合。13 关普通钥匙安静，怪物只能在 2 步警戒范围内发现玩家。

棕色箭头及三角格、Shadow 下一落点、新增危险菱形都来自同一个真实下一回合结算；警觉后的下一步会立刻显示。

## 灯、发电机与危险

统一结算顺序：玩家动作 → 道路与机关更新 → 小兽与 Shadow → 供能与短路 → 充电 → 危险判定 → 星片拾取与安全到达终点。

电源已启动、供能道路连通、没有短路且发生有效回合时：

`charge = min(maxCharge, charge + 1)`

当前最大值为 2。移动、等待、拼图和换空间都一样；无效输入和 Undo 不产生充电。Shadow 与灯在紫线中重新连通，当回合立即熄灯并把充电清零。断供停止充电并熄灯；解除短路不自动满电。灯边显示具体 0/2、1/2、2/2。早期灯已启动；12 关必须踩发电地板，OFF → ON 持续生效，满足条件时该次踏入即充第一格。金色能量流只沿实际可用的供能路径绘制。

所有危险统一由 `dangerCells(state, level)` 返回：Shadow 影响其对偶角点周围四个有效原始格，显示紫裂痕；未照亮区域显示灰斜纹与小灯印。逻辑、预测和渲染共用同一格集合及格中心映射，不靠 CSS 平移修正。重叠时每格只画一个危险层。6、7、8 关灰灯印都位于真实终点格；10 关删除了多余的第二块灰纹。到达安全终点即可获胜，无隐藏封印条件。

## 第 14、15 关：综合解谜

两关都包含转动领地、机关桥、带铃钥匙与门、小兽、影子、自由拼图、发电与照明、真实双界裂隙，以及可改变的空间边界。14 关的红色房间初始为纵向，需要转为横向才能取得星片。15 关的星片在红色房间内部，不能仅靠左右绕行跳过转动。

启动电源后，经紫线进入钥匙小岛，接桥取钥匙并逃离追击；再回到下方，旋转房间取星，接通终点旁的小环隔开影子，切换环面接通供电。15 关还可用扭转边界绕到下方。移除点火、桥、转房间、钥匙、裂隙或拓扑操作后，保存的策略会真实失败；这些检查不声称排除了所有其他策略。灯光和安全规则直接决定胜负，没有隐藏的完成清单。

`node tools/seamshift/finale-routes.mjs` 可重新生成普通和取星路线；`alternate-routes.mjs` 核验上述机制对保存策略的实际作用。匹配这些路线的局面有即时下一步提示，偏离后继续使用搜索提示。

## 三套说明，三个用途

- 本关新发现：地图顶部只保留“新发现”入口，不直接铺开规则；点击只看本关首次引入的机制，重复机制不再提示；第二关包括门、钥匙、警戒和三种边界，第三关再介绍上下连接。不会计时消失或自动弹出。
- 口袋说明书：右上角问号提供完整的操作、警戒、桥、拼图、灰灯印、充电和裂隙规则，使用实际地图 SVG。没有数学展开。
- 发现手记：文字为主的数学档案，按随机几何／空间拓扑／图论与对偶／游戏与算法分类。每项用简短文字解释概念与游戏中的体现；只解锁实际经历的内容。

按此前要求，主动连接半径玩法继续移除，当前关卡尺度固定。因此相关数学页保持未解锁，而不把机关桥伪称随机几何或渗流临界现象。数学手记明确区分有限边界、周期空间、平面对偶的适用范围和环面的非收缩环。

## 操作与布局

WASD / 方向键 / 滑动移动，Space 等待，Z 撤销，R 重开，T 切换本关允许的空间，H 渐进提示。点击或拖动碎片放置、旋转、交换、回收；同形每关一块，上面有玩家或小兽时拒绝改动且不计回合。

眼睛和“进入裂隙 / E”在地图容器右上工具行水平排列。眼睛只切换显示；进入裂隙按显式原始格—对偶角点映射真正切换世界。位置、对侧占据和危险检查由引擎与按钮共用 `riftAccess`。手机有效按钮至少 44px，iPad 使用完整可见高度，短横屏单独布局。非道路方块在电脑和手机都采用平面风格。

## 存档与迁移

继续使用 `seamloom.adventure.v4` 存储键，数据版本更新为 6。保留已解锁关卡。10、12、14、15 关布局版本为 14；第二关及 4–8 关为 13；9、13 关为 12，旧成绩转入 `priorBest`、旧尝试进入 `archivedAttempts`，新版分数不混用。1、3、11 关保持布局 11，兼容的尝试和完整 Undo 自动补齐新状态字段，不无故清掉其成绩。

每有效回合保存，页面隐藏或关闭时立即落盘。Restart 只重开当前关；Reset All Progress 经确认后删除本游戏全部新旧键并返回第一关，不清理无关数据。

## 验证范围与限制

自动测试覆盖真实动态通关、三星求解、睡眠／警觉时序、局部声音、充电和短路、危险坐标、自由拼图占据、裂隙一致性、存档迁移及完整 Undo。另通过浏览器实际操作检查手机、桌面与 iPad 尺寸；没有进行实体 iOS / Android 设备测试。

Voronoi 使用离散格中心的真实最近点计算，房间旋转确定而非重新随机生成。灯是图连通性和整数充电模型，不是完整物理电路。错误布局允许 Undo / Restart，不承诺所有错误状态都无需撤销即可获胜。

界面采用统一布局：关卡名、编号、步数、星片及历史星级固定一排；各关预留同样的拼图栏与四格空间位置，没有碎片或对应模式时保留空位。清除进度弹窗的取消与确认并排分隔，默认聚焦取消，取消后返回选关且不修改存档。

进入页面先显示旅程封面，点击“进入游戏”后恢复进度。新发现、进入裂隙和眼睛共用同一工具栏；新发现弹窗只保留规则与关闭按钮。地图小人、发电机和说明书复用相同 SVG；影子预测绘制在角色上方并带浅底圆形标记。

封面使用独立入口脚本，点击后再加载游戏；失败时显示提示并可重试。构建会为 HTML、脚本依赖、Worker、样式与封面生成统一内容版本，避免新封面与旧缓存脚本混用。入口 DOM 集成测试覆盖新存档、恢复存档、存储不可用，以及点击进入后的真实移动。
