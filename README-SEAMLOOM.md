# SEAMLOOM — A World of Twisted Paths

轻量、无后端的回合迷宫。复用原有原生 ES modules + SVG 架构，无运行时依赖。游戏地址保留为 `/seamshift/`；个人站根地址暂时返回真实 HTTP 404，首页源文件保留。

`npm run dev` 本地预览；`npm test` 回归测试；`npm run build` 独立生产构建。GitHub Pages / Jekyll 直接复制独立游戏 HTML 和相对资源路径。

## 当前规则

- 桥由地图同纹地板触发，每次重新进入触发一次，也支持配置单次触发。桥长 2–3 格，采用细木板、栏杆和断口。桥上有玩家或小兽时拒绝断桥并说明原因。没有独立桥按钮，也没有连接范围／尺度玩法。
- 普通空白建路区域都允许放置任意形状碎片；无编号配对和唯一高亮槽。每关每种形状只出现一块，可以交换、取回和旋转。玩家或小兽在上面时，所有改动都拒绝，且不消耗回合。
- Plane 封闭；Cylinder 左右同向；Möbius 左右反序；Torus 左右、上下周期连接。边缘配对标记与实际图一致。第三关只允许 Plane / Torus。
- 普通怪物睡眠闭眼，醒来睁眼；警戒或取钥匙唤醒后，每次有效回合在当前真实玩家图上 BFS 追一步。在双界关，玩家离开后小兽继续追向最后一个普通入口。
- Shadow 只走真实对偶角点：一条玩家道路接通，交叉的紫线关闭。它所在角点周围四格为危险，周期边界使用同一几何规则。第四关 Shadow 静止。普通小兽的箭头、Shadow 下一落点及新增危险格，均调用真实下一回合结算来预测。
- 灯显式区分 Unpowered / Ready / Charging / Lit / Shorted。短路立即熄灭；断供或短路每回合损失一格能量。点亮需要供能、已启动、无短路，连续充能两回合。早期守护灯配置为已启动；12、15 关必须踩点火机关。解除短路本身不会启动能源。
- 黑暗地板用暗色叉纹明确表示，只有灯亮才安全；灯灭会在同回合更新危险。普通终点没有隐藏封印条件，安全到达立即通关。
- 双界只能通过显式配置的普通格—对偶角点入口切换。普通物品和终点不能在对偶世界触发。另一侧被占据、危险或节点无效时拒绝切换。
- Voronoi 每个位置按真实欧氏距离归属于最近控制点（距离相等按配置顺序）。对应地板让固定 3×3 房间转 90°，更新真实地板和端口，原始／对偶图同步改变。房间里有实体时拒绝旋转。

## 操作、视觉与发现

方向键 / WASD / 地图滑动移动；Space / 等待推进一回合；Z 撤销；R 重开；T 切换当前允许的空间；E 在裂隙切换双界；H 渐进提示。手机支持点选、放置、旋转、交换与拖放。

眼睛固定在地图容器右上方，切换道路／裂隙显示，不消耗回合。桌面与手机使用同一套浅色平面非道路方块。两座断桥的木纹、机关图样，以及怪物闭眼／睁眼、Shadow、陷阱、灯、能量、裂隙等，地图和说明书共用实际 SVG 图形。

发现手记按“世界规则／世界居民／能量与机关／数学秘密”分类，只有实际遇见或操作的内容才解锁。地图顶部只在发现尚未读过的游戏机制时显示 !；数学说明自愿展开，不产生强制提示。四种空间在同一张小地图对照卡中说明。Help 直接展示已解锁图例，无二次进入按钮。首次三条基础规则不阻拦操作并自动淡出；打开即进入当前关，无开始按钮。

## 存档与版本迁移

继续使用 `seamloom.adventure.v4` 存储键，数据版本为 5、布局版本为 11。保留已完成关卡的解锁；本次重做关卡的旧成绩转入 `priorBest`（选关可见旧版星级与步数），新版星级和最佳步数重新累计，不把失效三星当作新版记录。不兼容的当前尝试保存到 `archivedAttempts`；新版完整保存世界、机关桥、房间旋转、灯状态、能量、怪物时钟和 Undo。

每回合合并写存档，隐藏页面／关闭立即保存。刷新恢复实际进度。Restart 只重开本关；Reset All Progress 经确认后删除本游戏全部新旧存储键，立即回到第一关，不清除无关网站数据。

## 限制与扩展

所有核心玩法离线运行，配置驱动，可继续添加 16–20 关。动态房间采用离散格中心的 Voronoi 归属与确定的方格旋转，不宣称连续多边形物理；没有额外随机渗流事件。可逆试错由完整 Undo 和 Restart 保证，不承诺每个错误状态都无需撤销即可到达终点。

移动端缓存静态地图、分层更新 SVG，低性能模式停用持续动画。生产构建只打包静态资源，没有游戏服务器依赖。
